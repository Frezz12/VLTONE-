# Creator: DSP без C++

Этот контракт описывает нодовое ядро Creator 3. Исходники C++ по-прежнему используют SDK/ABI 1: новые коллекции графа **не добавляют типы в C++-заголовок**.

[NODE_REFERENCE.json](NODE_REFERENCE.json) содержит полный реестр, выгруженный из программы: стабильные ID каждой ноды и её портов, типы, обязательные входы, диапазоны, значения сброса и списки режимов. `parameter_index` связывает вход с полем в массиве `parameters`; −1 означает отсутствие ручного численного поля. Для динамических нод это исходная схема: History меняет порты по `valueType`, коллекции — по Array/List, Custom Node — по определению подграфа, C++ Function — по проверенной сигнатуре. Вместимость 0 в статическом описании означает, что её задаёт нода или подключённая коллекция.

Версии файлов: `.vltcreator` — 3, `.vltmini` — 5, `.vltnode` — 1, проект DAW — 16, пресет полосы — 6. Старые графы версий 1–4 сохраняют свой прежний исполнитель и звучание. Новые операции требуют определения версии 5.

## Начало работы

Открой Creator и добавляй ноды через библиотеку, поиск Tab или правую кнопку на канвасе. Подключай выход к входу одинакового типа. Поле с подключением получает значение из связи; его ручное значение снова доступно после отключения. Для чисел работают вертикальное перетаскивание, Shift, точный ввод двойным кликом, клавиатура и сброс Ctrl-кликом. Один жест создаёт одну запись Undo.

Ноду из левой библиотеки можно перетащить в нужное место холста; двойной щелчок и Enter добавляют её в центр видимой области. Категории сворачиваются щелчком по заголовку или стрелке. Поиск временно раскрывает найденные категории и восстанавливает их состояние после очистки. Двойной щелчок по проводу удаляет связь; Undo возвращает её. На верхней панели иконка слоёв создаёт ноду из выделения, а иконка импорта открывает `.vltnode`; названия команд доступны в подсказках.

Внешние ручки на карточке мини-модуля задаёт Interface. Их максимум две; внутренних численных полей и связей может быть гораздо больше. Значения передаются в физических единицах: 1000 Hz — это число 1000, коэффициент усиления 0.5 — число 0.5. Проверяй диапазон внешней ручки перед подключением.

Compile проверяет проект, готовит DSP и атомарно обновляет установленный мини-модуль. Незавершённую схему можно сохранить и продолжить позже. Ошибка подготовки оставляет прежний файл и работающие экземпляры.

## Типы портов

| Тип / ID | Содержание | Использование |
|---|---|---|
| Audio / `audio` | Аудиокадр с независимыми L/R | Звук; в моно оба внутренних компонента соответствуют одному каналу |
| Number / `number` | Число с двойной точностью на каждом отсчёте | Формулы, модуляция, коэффициенты |
| Gate / `gate` | Логическое значение | Разрешение записи, Reset, выбор ветви |
| Integer / `integer` | Целый индекс или счётчик | Индексы коллекций; явное преобразование из Number |
| Array / `array` | Числовой массив фиксированной длины | FIR, таблицы, коэффициенты |
| List / `list` | Числовой список переменной длины | Добавление/удаление в пределах подготовленной вместимости |
| Buffer / `buffer` | Ссылка на историю аудио | Один записывающий Delay Buffer, несколько Read Delay Tap |
| Function / `function` | Вызываемая C++-функция с сигнатурой | SDK 1; отдельная янтарная пунктирная связь |

Integer получается через Number to Integer: дробная часть отбрасывается к нулю, диапазон ограничен −2³¹…2³¹−1. Обратное преобразование — Integer to Number. Gate to Number даёт 0/1; Number to Gate проверяет отличие от нуля. Неявных преобразований нет.

Split Stereo выдаёт два Number: `left`, `right`. Join Stereo принимает их обратно. Encode Mid–Side выдаёт `(L+R)/2` и `(L−R)/2`; Decode восстанавливает L=M+S, R=M−S. Для сохранения стерео обрабатывай обе ветви. Audio to Number — явное сведение/выбор канала; математическая Number-нода сама не сводит стерео.

Цвет и форма порта обозначают тип, а область захвата остаётся 24×24 логических пикселя. Полное имя и тип видны в подсказке.

## Порядок вычислений и память

Для каждого отсчёта исполнитель читает старую память, вычисляет обычные операции в порядке зависимостей и затем фиксирует все записи памяти. Несколько выходов одной ноды вычисляются одним вызовом. Разбиение аудио на блоки не меняет это правило.

**Variable / History** имеет тип значения, начальное значение, `next`, `write` и `reset`. Выход — состояние предыдущего отсчёта. Неподключённый `write` разрешает запись. Активный Reset имеет приоритет и восстанавливает начальное состояние при фиксации; его результат виден на следующем отсчёте. Подключи Gate=false к Write enable, чтобы удерживать состояние. Для Array/List начальные элементы и вместимость задаются в инспекторе. Имена переменных — подписи, а связи адресуют стабильные ID.

Пример рекуррентного фильтра: Input → Add Audio; History(Audio) → Scale Audio(0.5) → второй вход Add Audio; выход суммы одновременно подключён к Output и History.next. Получается `y[n] = x[n] + 0.5*y[n−1]`.

Каждый замкнутый путь обязан пересекать History или Delay Buffer. Прямой цикл математических операций запрещён. Память нужна на **каждом** замкнутом пути, а не просто где-нибудь в схеме. Accumulator, Counter и готовый фильтр не заменяют явную границу обратной связи. Цикл через готовый эффект, C++-ноду или границу передискретизации не поддерживается; проверка сообщает причину.

Связанные элементарные операции объединяются в подготовленные участки и исполняются в одном цикле по отсчётам. Внешний AudioGraph/GraphProcessor(1) запускается на блок, а не на каждый отсчёт. Готовые эффекты и C++ сохраняют свою блочную обработку. Подготовка, разворачивание и выделение памяти происходят до аудиопотока.

## Операции

| Группа | Ноды и семантика |
|---|---|
| Аудио | Add/Subtract/Multiply Audio, Scale Audio без скрытого сглаживания, Split/Join Stereo, Mid–Side, Select Audio |
| Математика | Существующие арифметические операции; Exp, Log, Log2, Log10, Tanh, Atan, Sign, Floor, Ceiling, Round, Fraction, Modulo, Wrap, Fold, Lerp, Smoothstep |
| Уровни | Linear to dB, dB to Linear, Peak, Window RMS, Attack/Release, Slew Limiter |
| Логика | AND, OR, XOR, NOT, Rising/Falling Edge, Gate↔Number, выбор числа или аудио |
| Память | History, Accumulator, Counter, Delay Buffer, Read Delay Tap, Time/Context |
| Фильтры | One Pole, Biquad, Biquad Coefficients, FIR, DC Block |
| Характер | Hard Clip, Transfer Curve, Table Lookup |
| Коллекции | Array, List, Length, Get/Set, Append, Remove, Clear, Sum/Minimum/Maximum, Map, Reduce |

Fraction(x)=x−floor(x), в том числе для отрицательных x. Modulo использует остаток `fmod`; Wrap всегда возвращает значение в заданном диапазоне, Fold отражает его от границ. Lerp разрешает экстраполяцию; Smoothstep ограничивает нормализованную позицию 0…1. При совпадающих границах Wrap/Fold возвращают границу.

Деление на почти нулевой знаменатель возвращает 0. Логарифмы ограничивают аргумент снизу 10⁻²⁰. Exp ограничивает аргумент −80…ln(10⁶), dB to Linear — −180…120 dB; Linear to dB использует модуль и пол −180 dB. Недопустимый результат (NaN/Inf, например Power отрицательного числа в дробной степени) останавливает модуль с диагностикой. Экспорт сообщает ошибку.

Peak берёт максимум модулей L/R. Window RMS усредняет квадрат по двум каналам и временному окну; его окно подготавливается заранее. Attack/Release — однополюсное сглаживание: для роста выбран Attack, для спада Release, времена в миллисекундах. Slew ограничивает изменение в единицах в секунду. Для компрессора удобно сначала сгладить положительное превышение порога, а затем умножить на отрицательный наклон характеристики.

One Pole: `y[n]=(1−p)*x[n]+p*y[n−1]`, независимое состояние L/R. Biquad принимает Array ровно из пяти нормализованных коэффициентов `[b0,b1,b2,a1,a2]`: `y=b0*x+b1*x[-1]+b2*x[-2]−a1*y[-1]−a2*y[-2]`. Biquad Coefficients выдаёт эти коэффициенты для LP/HP/BP/notch/all-pass/bell/low-shelf/high-shelf. Формулы основаны на [Audio EQ Cookbook, W3C](https://www.w3.org/TR/audio-eq-cookbook/). Частота ограничена 0.49 Fs. Собственные коэффициенты обязаны задавать устойчивую систему: фильтр не скрывает нестабильность.

FIR сворачивает аудио с массивом коэффициентов, без аллокаций при изменении его значений. DC Block реализует удаление постоянной составляющей с настраиваемой частотой. Hard Clip ограничивает оба канала. Transfer Curve принимает Number; точки X/Y редактируются в инспекторе, X строго возрастает, интерполяция линейная, за диапазоном используются крайние Y. Table Lookup читает Array по нормализованной позиции 0…1 с линейной интерполяцией.

Time/Context предоставляет Sample Rate, Time (секунды временной шкалы), Tempo, Beat и Playing. Counter считает передние фронты и сбрасывается Gate Reset; Accumulator суммирует приращение на каждом отсчёте. Их состояние отдельно у каждого экземпляра.

## Задержки и передискретизация

Delay Buffer заранее резервирует Maximum delay (до 10 секунд). Несколько Read Delay Tap могут читать один Buffer с разными временами. Чтение имеет минимум один отсчёт, дробная задержка интерполируется линейно. Вход записи фиксируется после вычислений; Reset очищает историю на переднем фронте. Изменение времени не добавляет скрытого сглаживания: при необходимости сглаживай время отдельной нодой.

Алгоритмическая память History, FIR, фильтра или Delay Buffer не компенсируется PDC. Она является частью эффекта. Произвольная обратная связь объявляет неизвестный хвост; для экспорта используй существующий режим до затухания с ограничением максимальной длительности.

Своя нода с элементарными операциями может работать на 1×, 2× или 4×. Используется half-band FIR длиной 65 отсчётов: собственная техническая задержка границы 32 отсчёта при 2× и 48 при 4× в частоте вызывающего графа. Она участвует в PDC; параллельные ветви выравниваются. Audio и Number ресемплируются, дискретные Gate/Integer и коллекции удерживают значение; Buffer/Function через границу частот не передаются. Готовые эффекты и C++ доступны в обычном подграфе 1×. Обратная связь не пересекает границу частот.

## Коллекции и Map/Reduce

Вместимость — 1…4096 чисел. Array имеет фиксированную длину; незаданные начальные элементы равны нулю. List содержит только введённые элементы и меняет длину без выделения памяти. Изменения коллекций дают новый выход ноды; чтобы сохранить его до следующего отсчёта, подключи выход к History соответствующего типа. Отдельная Array/List-нода выдаёт заданные начальные данные на каждом отсчёте.

- Get с недопустимым индексом: значение 0, Valid=false.
- Set/Remove с недопустимым индексом и Append в полный список: исходная коллекция без изменений, Success=false.
- Clear: Array заполняется нулями, List становится пустым.
- Sum пустой коллекции равен 0; Minimum/Maximum пустой коллекции также дают 0.

При добавлении Map или Reduce автоматически создаётся редактируемая внутренняя схема. Открой её двойным кликом или кнопкой инспектора. Сигнатура Map: `item:Number`, `index:Integer` → один Number. Reduce добавляет `accumulator:Number` и начинает с Initial. Стабильные ID этих портов — `item`, `index`, `accumulator`; подписи можно менять. Внутри можно использовать элементарные ноды и память; готовые эффекты и C++ в теле коллекции запрещены. Каждая позиция имеет независимое подготовленное состояние. Выполняется только фактическая длина коллекции; верхняя граница итераций — вместимость. Рекурсия запрещена.

## Собственные ноды и файлы

Выдели ноды обработки и выбери «Создать ноду из выделения». Пересекающие границу связи становятся портами. Нужен хотя бы один подключённый выход. Input/Output/Interface остаются границами модуля. Двойной клик открывает внутреннюю схему, верхняя строка показывает путь и возвращает на предыдущий уровень. Координаты и масштаб хранятся отдельно для каждой схемы.

«Изменить порты» задаёт имена, порядок, типы, единицы, диапазоны, начальные значения, логарифмическую шкалу и вместимость. Стабильные ID скрыты от случайного редактирования. Удаление или смена типа оставляет проблемные связи в черновике; их надо исправить перед Compile. Удалённая граница остаётся видимой и внутри ноды. Начальное значение Integer должно быть целым, Gate — 0 или 1.

Служебный `stateKey` сохраняет исходную идентичность генератора при упаковке/разворачивании, чтобы его начальная случайная последовательность не менялась из-за нового внутреннего ID. Память экземпляров остаётся раздельной; одинаковая начальная последовательность не означает общее состояние. Для разных последовательностей у экземпляров меняй параметр Seed внутри независимых определений.

Несколько экземпляров ссылаются на одно определение: изменение внутренней схемы обновляет тип в текущем проекте. DSP-память при этом принадлежит экземпляру. «Сделать независимой» копирует определение с зависимостями. «Развернуть в схему» раскрывает экземпляр 1×; для передискретизированной ноды сначала выбери 1×, поскольку её частотная граница влияет на звук.

Экспорт ноды сохраняет `.vltnode` версии 1 с зависимостями. Личная библиотека находится в `Documents/VLTONE/CreatorNodes`. Файлы из неё видны рядом с определениями текущего проекта в «Мои ноды». Импорт копирует определение внутрь проекта. Если ID совпадает, но содержимое отличается, можно явно обновить тип в этом проекте либо импортировать независимую копию. Замена библиотечного файла сама по себе не меняет другие проекты. Готовый мини-модуль переносится одним `.vltmini`, включающим определения, начальные данные, исходники C++ и переносимый WebAssembly, если он используется. Подготовленные планы и нативный машинный код в файл не записываются.

## Лимиты и совместимость

До 512 развёрнутых нод, 2048 связей, 8 уровней вложенности и 16 МиБ подготовленного состояния элементарного DSP на мини-модуль. Map/Reduce заранее создают состояние для своей вместимости, поэтому большая ёмкость со сложным телом может достичь лимита памяти. Нода имеет до 16 входов и 16 выходов. По-прежнему максимум три карточки на Channel Strip и две внешние ручки на карточке.

C++ сохраняет свои отдельные 64 исполнительных слота, ограничения SDK 1 и линейную память WebAssembly. 90 математических нод до C++-ноды не расходуют C++-слоты. Неизвестное определение сохраняется как недоступное и не публикует неподготовленный DSP.

## Готовые учебные схемы

В [examples/nodes](examples/nodes) находятся редактируемые проекты и готовые `.vltmini`:

1. **NodeCompressor** — Peak → dB → превышение порога → Attack/Release → собственная характеристика Ratio → линейное усиление. Ручки Threshold и Ratio; времена редактируются внутри схемы.
2. **NodeEqualizer** — расчёт коэффициентов bell-секции и отдельный Biquad. Ручки Frequency и Gain; Q и тип доступны внутри.
3. **NodeSaturator4x** — собственная нода со стерео Tanh на 4×, ручки Drive и Level. В комплекте отдельный `StereoWaveshaper.vltnode`.
4. **NodeFeedbackDelay** — запись суммы входа и возврата в Buffer, отдельное чтение отвода, Time и Feedback. Максимальное время буфера 2 секунды.

Для нейросети: используй точные ID типов и портов из реестра и примеров; сохраняй явные стереоветви, помещай History в каждый цикл, не придумывай C++-типы коллекций. Опиши шкалы двух внешних ручек. Сначала проверь схему на конечные значения, затем на одинаковый результат при разных блоках и после сохранения/загрузки.
