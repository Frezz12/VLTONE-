An extension can be a single command, a custom window or a docked panel. Lua ships with VLTONE; no interpreter or compiler installation is needed.

Install and run

  1. Open Scripts → Script manager → Library → Install….
  2. Choose a .lua, .vltscript or Lua .vltcreator file. Installation does not execute code.
  3. Expand an extension, select a command and click Run command.
  4. Select the required clips or notes first. A context menu passes the object under the pointer, even when it differs from global selection.

Use Run file… for a one-off script, or Choose command… to search installed actions. In piano roll, use Alt + right-click or the actions menu; ordinary right-click retains note deletion.

A place for each task

SectionPurpose
LibraryInstall, find and run commands. Configure shortcuts and context menus under Command; enabling and autostart under Extension; access under Permissions.
ActivityInspect active and completed runs. Select one to view its log, stop it or open an error location in Creator.
HelpUser guide, SDK and creating a new extension.

The icon actions at the top of Library update from file, export, open Creator and remove the selected extension. Hover for a description. Updates retain bindings when extension and command IDs are stable.

Assign a shortcut under Command. Conflicts are checked before saving. Enable the supported context menu locations and optionally pin a command directly instead of inside the Scripts submenu.

Design your toolbar

  1. Enable Scripts → Script toolbar; it is hidden by default.
  2. Open configuration from the toolbar menu. This is a separate modeless window, so your project remains accessible.
  3. Click Add… and choose a command. Use arrows or drag to reorder; add separators to form groups.
  4. In Appearance, choose a label and Text, Image only or Image and text. The preview updates immediately.
  5. Choose a photo or icon: PNG, JPEG, WebP, SVG, BMP or ICO, up to 8 MiB and 64 megapixels. Saving stores a persistent image copy.
  6. Click Save. The Arguments tab normally stays {}; use special values only when the command's author documents them.

Dock the toolbar at any edge or float it. The menu provides placement controls without dragging. Placement, visibility and button configuration survive restart.

Data access

Declared project and file read permissions automatically cover project data and linked media, unless explicitly revoked. Other files must be chosen in a file dialog or belong to a folder granted in the manager.

CapabilityPolicy
Read project/mediaAutomatic for declared permissions. Does not expose the whole disk or unrelated neighboring files.
Edit project/transportExplicit approval. Edit batches use normal Undo. Script editing is blocked in collaborative projects.
Write filesExplicit approval plus a chosen destination. Original media is preserved.
Network/processesSeparate approval. External processes also require a specifically granted executable.

Autostart is off on installation and enabled per extension. A failing autostart tool is suspended until you enable it again. Stop all cancels script instances and their jobs.

Build with code or AI

Choose Create in Creator… → Lua script. Mini modules remain a separate project type. Files/resources are on the left, code and diagnostics in the center, and AI on the right. Ctrl + Space opens completion; Ctrl + F finds text.

  1. Describe inputs, the desired output and UI to AI, for example a project-media table with an analysis button.
  2. Ask it to use the installed SDK, validate the sources and run Preview copy.
  3. Preview uses a project copy and test files. Run in real project is a separate action.
  4. Save, install and bind the command to a key or toolbar button.

Export .vltscript to share code and resources. Recipients need a VLTONE build supporting the package's SDK. The developer guide includes examples and API conventions.

Troubleshooting

SymptomCheck
Missing clip menu actionEnable the extension, ensure it declares clip context, and enable that context in the manager.
Slicer does not cutUse an audio clip, approve project editing and inspect Activity. Collaboration blocks edits. Reversed, stretched or composite clips require explicit source-mapping support from the algorithm.
File deniedIt must be linked project media, a package resource or an explicitly chosen file/folder. Review permissions if access was revoked.
Activate the tool's projectReturn to the tab named in the tool window. Tools stay bound to their original project.
Revision/identity errorThe project changed or a device was replaced. Refresh and retry; authors must reread the snapshot before applying changes.
Hung or stopped scriptStop it in Activity, inspect the error and open the source location in Creator. Long work must use jobs or bounded handlers.
