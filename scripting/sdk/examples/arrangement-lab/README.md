# Arrangement Lab

Полноценный пример Lua SDK: четыре вкладки, собственный canvas, MIDI-генератор,
синтез шести аудиопартий, микшер и проверка результата. Внешние инструменты,
сеть и системные процессы не нужны. `resources/block.wav` — 8192 нулевых
отсчёта для получения ограниченного PCM-буфера через штатный `audio.read`.

Откройте пакет в Lua Creator, проверьте и установите его. В меню скриптов
появятся **Arrangement Lab — открыть** и **проверить генератор**.
Через MCP используйте `run_script` с ID `studio.vltone.arrangement-lab/open`.

- **Композиция:** тональность, гармония, 4–16 тактов, темп, seed и обзор шести
  партий. Одинаковые настройки дают одинаковые ноты.
- **Ритм:** 16 шагов для Kick/Snare/Hats; мышь либо стрелки и пробел/Enter.
  `R` возвращает рисунок генератора. Swing, плотность и humanize меняют план.
- **Микшер:** уровни, панорама и mute. Кнопка применения записывает каналы
  одним атомарным пакетом и одним шагом Undo.
- **Проверки:** сверка MIDI в настоящем проекте, рендер снимка, измерение
  пика/RMS, обзор дорожек и журнал. Измерения получены из WAV.

«Применить MIDI» обновляет шесть дорожек `[Lab MIDI]`. Им можно назначить
собственные инструменты. «Собрать 6 аудиостемов» сначала применяет MIDI и
выбранный темп, затем синтезирует звук в отдельные дорожки `[Lab]`.
Kick, snare, hats, bass, keys и arp синтезируются самим Lua-кодом при 24 кГц.
Публикация всех стемов — один Undo; создание дорожек и MIDI — отдельные этапы.
Повторная сборка заменяет клипы этого расширения в его дорожках.

Синтез выполняется по 8192 отсчёта за callback. Кнопка отмены закрывает
незавершённые файлы; до завершения всех шести партий аудиоклипы не добавляются.
Закрытие окна или отключение MCP-клиента останавливает принадлежащий ему запуск.
Завершённые правки остаются. Импортированные WAV сохраняются с проектом.

Исходники `music.lua` и `synth.lua` отделены от окна. `verify.lua` проверяет
9 комбинаций длины/гармонии: диапазоны, границы нот, уникальность ID,
повторяемость и ручное изменение ритма. Проверка не меняет проект.

Для автоматической проверки окна: `script_ui/list`, `get`, `click`, `tab`,
`pointer`, `key`; снимок — `capture_view` с `view: "script"`, `runId` и
`windowId: "lab"`. Эти инструменты работают только с собственным запуском.
