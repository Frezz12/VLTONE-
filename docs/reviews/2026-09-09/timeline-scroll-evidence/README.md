# Изолированные измерения прокрутки

Результаты относятся к ревью `../timeline-scroll-review.md`. Это диагностические пробы, не исправления и не добавленные production-тесты. Они не открывают пользовательский проект, аудиоустройство или окно приложения, не меняют настройки. Бинарники собираются во временный каталог.

`waveform-paint-snapshot.cpp` — копия production `app/WaveformPaint.cpp` на момент ревью, без test-only функции `checkWaveformBaselineForTest`. `waveform-paint-instrumented.cpp` отличается диагностическим флагом, позволяющим пропустить единственный `drawPath`. Header и структуры peaks берутся из проекта.

На macOS с установленными Qt 6 и pkg-config:

```sh
python3 docs/reviews/2026-09-09/timeline-scroll-evidence/run_waveform_probe.py ab
python3 docs/reviews/2026-09-09/timeline-scroll-evidence/run_waveform_probe.py baseline
```

A/B занимает несколько секунд, длинный baseline может занимать около двух минут. Не запускать одновременно с другими бенчмарками/сборкой. Для исходных результатов использованы AppleClang, `-O2`, Qt 6.11.2, macOS arm64. Числа в `*-results.txt` — сохранённые результаты первоначальных прогонов, а не обязательные пороги для другой машины.

Baseline: 12 волн, 1600×960 логических пикселей, DPR 1/2, 240 итераций. Сравниваются повторная растеризация с попаданием в кэш геометрии и горизонтальный шаг 3 px. В первоначальной временной пробе также был некорректный опыт копирования изображения на самого себя; он исключён из сохранённого harness и результатов и нигде не используется как доказательство.

A/B: 8 волн, 1600×960, DPR 2, 30 итераций; перед каждым режимом очищается кэш геометрии. Отдельная immutable подложка строится заранее. Её копирование — оценка стоимости копирования, не эмуляция готового исправления прокрутки. Отключение одного `drawPath` сохраняет вычисление точек, вставку в кэш, очистку холста и ось. Это позволяет отделить геометрию от растеризации.

Аудио: `audio-results.txt` содержит команды и полный вывод свежего standalone `tests/audio_engine_bench.cpp`, собранного с текущими исходниками engine, а не старым бинарником из build. Для обычного воспроизведения этого существующего теста можно собрать цель `audio_engine_bench` в своей актуальной CMake-сборке и передать аргументы из файла. Вызывающий поток и семь helpers зарегистрированы realtime; устройство/workgroup, GUI и сторонние плагины отсутствуют. `cpu_ms_per_block` — совокупное CPU-время процесса; его нельзя приравнивать к длительности одного GUI-кадра.

`source-sha256.json` фиксирует прочитанную версию основных файлов после ревью. Рабочее дерево содержало изменения других задач; benchmark waveform использует сохранённую копию функции, остальные ссылки отчёта относятся к текущим файлам проекта.
