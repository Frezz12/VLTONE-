# Общий Bounce in Place для нескольких дорожек

Контроллер создавал отдельное задание рендера на каждый выбранный канал. Теперь задания объединяются после разрешения связанных источников Pattern. Все выбранные инструменты проходят через один аудиограф и общие эффекты одновременно. Результат — один файл, один аудиоклип и одна новая аудиодорожка с собственными работающими контролами канала. Невыбранные источники не включаются в рендер. Отрендеренные участки исходных клипов заглушаются; отмена операции и Undo/Redo сохраняют прежнюю атомарность.

| До | После | Зачем |
|---|---|---|
| Несколько выбранных дорожек создавали несколько результатов | Выделение сводится в один общий аудиоклип | Соответствовать действию пользователя |
| Диалог предлагал неоднозначное «Replace in place» и предупреждал о сумме раздельных файлов | Для общего рендера указано «Свести в одну новую аудиодорожку» и объяснено заглушение исходных участков | Показывать фактический результат до запуска |

Операции с одним исходным каналом сохраняют прежние варианты Replace/New Track. Glue аудиоклипов на одной дорожке продолжает пользоваться тем же путём Bounce.

Проверены `processing_render_test` и `render_ui_test`. Новая проверка создаёт четыре MIDI-дорожки с семплерами, разными громкостью и панорамой и общим компрессором. Выполняются оба пути выбора — целые дорожки и отдельные клипы. Общий файл сравнивается с эталонным миксом выбранных источников по всем семплам с допустимым отклонением 0.00002. Проверены единственный результат, его позиция, исключение пятой дорожки и пересекающегося невыбранного клипа, заглушение только выбранного участка, отмена и одна операция Undo/Redo. Существующие проверки одиночного Bounce, MIDI, Pattern и офлайн-обработки также прошли. UI-проверка подтверждает общий результат для нескольких каналов и прежние варианты для одного.
