# Статус процессной архитектуры

8 октября 2026 года экспериментальный отдельный аудиопроцесс и процессы каждого экземпляра плагина удалены. Приложение использует текущий `AudioRuntime` напрямую и встраивает нативные редакторы в своё рабочее пространство.

Сканирование, экспорт и файловые задания сохраняют отдельных исполнителей. Актуальное описание обработки и границ защиты: [Аудиодвижок и границы процессов](../implementation/process-isolation.md).
