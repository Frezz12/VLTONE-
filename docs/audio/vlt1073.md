# VLT 1073

Built-in VLTONE preamplifier / equalizer, UID `daw.1073`, state version 1.
The native editor follows the supplied two-column reference without its wood
surround, white margin or explanatory callouts. The left emblem says VLT;
the emblem beside the fader is omitted at the user's request. Circular red
and blue caps have two opposed moulded tabs on machined metal collars.
Lighting stays fixed as they rotate. Fine enamel / metal grain is cached
with the plate; short contact shadows replace broad drop shadows.

## Controls and persistence

The public parameter order is fixed: `inputMode`, `inputEnabled`, `micGain`,
`lineGain`, `micZ`, `pad`, `highGain`, `midFrequency`, `midGain`, `lowFrequency`,
`lowGain`, `highPass`, `eqEnabled`, `phase`, `level`, `output`.
Mode 0 is LINE, mode 1 is MIC. Frequency indices are OFF followed by ascending
physical frequency. MIC and LINE retain independent gains. Gain is quantized
to 5 dB in the processor, including automation and restored state. Level −90
dB is an exact mute sentinel; it is shown as −∞. POWER is the insert's host
bypass. No automatic gain compensation is performed.

Drag vertically; hold Shift for fine adjustment. Double-click resets. Enter
opens a native value editor; arrows adjust values. The outer MID/LF annuli
and their printed frequency labels select frequency, while the inner knobs
change gain. MIC/LINE labels select the input. OFF mutes the input. Escape
cancels a drag. A completed gesture creates one undo entry. Right-click any
parameter for automation. Keyboard focus and accessible value interfaces are
provided independently for the concentric controls. The rack uses the
existing generic parameter view; the full face opens in the effect editor.
Controls have no painted focus outlines. A floating value readout appears
during dragging and keyboard adjustment; the Level readout follows its cap
and displays dB or −∞. MIC Z and PAD can be positioned in either input mode,
but affect audio only in MIC. POWER redraws immediately with host bypass,
including undo and external changes.

## Source material and model status

Primary references:

- [Neve 1073/1084 drawings, including EH10023 and BA182/C, BA205, BA211, BA283/BA284](https://medias.audiofanzine.com/files/neve-1073-1084-user-manual-issue5-478436.pdf)
- [AMS Neve original operating specifications](https://www.ams-neve.com/wp-content/uploads/2021/08/1073_1084_user_manual_issue_5_1-1-.pdf)
- [Universal Audio control and signal-path documentation](https://help.uaudio.com/hc/en-us/articles/4419497223188-Neve-1073-Preamp-EQ-Manual)
- Installed Arturia `pre-1973_Manual_1_2_EN.pdf` and the locally installed Pre 1973 VST3.

**This implementation is a reduced model, not a certified component-exact
transcription of EH10023. The requested ≤0.25 dB agreement with an independent
calculation of the complete original circuit has not been established.**
The drawings establish the topology, switching, passive filter families,
single-ended amplifiers and fader placement. They do not provide all the
magnetic material curves, winding parasitics or transistor operating curves
needed to identify a unique nonlinear model. The equations below explicitly
identify the implemented reduction; they must not be presented as a measured
hardware or UAD match.

The shared feedback node has three RC/RLC branches with independent input and
feedback histories. LF observes an RC capacitor, HF its resistor, and the
presence branch observes the resistor of a series RLC resonator. Kirchhoff's
node equation is `y + Σ cut_i * H_i(y) = x + Σ boost_i * H_i(x)`.
Band conductance is `10^(abs(gain)/20) − 1`; the presence damping is 0.8.
Shelf pole positions move with gain. The branch states use trapezoidal
companion equations, with a direct term plus a history term. Substitution
into the node equation solves the feedback algebraically, with no iterations.
This retains cross-band feedback interaction instead of cascading three
independent cookbook biquads. B182/C is reduced to a terminated third-order
high-pass response. This reduction does not preserve every original passive
component value or every interaction of the transistor feedback networks.

BA284/BA283 stages use a third-order emitter-degeneration approximation with
a smooth collector headroom boundary and an asymmetrical bias. Input and
output transformers use flux integrators, a reversible magnetization curve
and a bounded hysteretic memory. These headroom, bias, damping, coercivity
and loading coefficients are model assumptions, not extracted hardware
measurements. The 10468 and 31267 paths use different loading/drive factors;
MIC Z loads a fixed virtual 150 Ω source. HI is 1200 Ω below the additional
gain stage and 600 Ω above it; LO is 300 Ω. PAD is applied before the mic
amplifier. The additional stage engages at 55 dB. EQ/fader loading remains in
the model when EQ is bypassed. Level drives the output amplifier and magnetic
memory; Output and polarity are applied after the final decimator.

Signal calibration: a −18 dBFS peak sine represents +4 dBu RMS. The conversion
uses 0.775 V RMS as 0 dBu. The software uses floating-point headroom; 0 dBFS
inside the plugin is not a hard output clip. The host remains responsible for
final device/export clipping.

## Realtime and state contracts

Two cascaded `HalfBandFir65` interpolation stages and two decimation stages
provide 4× processing and 48 samples of latency. Channel memories are separate.
Control solutions update every 32 base-rate samples; their coefficients and
amplitudes are interpolated every sample. Frame-offset parameter events are
handled before the corresponding audio segment. The first segment after reset
establishes its operating point after frame-zero state events, preventing
different initialization during playback and offline rendering.

Processing uses fixed storage, lock-free parameter atomics, bounded algebraic
solves and no allocation. Reset clears transformer, filter and resampler
memories. Input NaN/Inf becomes silence. State is parsed and validated before
any values are committed. Host bypass, mixing, PDC, project serialization,
copying, automation, offline export and freeze use the standard PluginInstance
integration. Shared-project allowlists and the v6 JSON Schema referenced by
OpenAPI include the new UID; the TypeScript client is regenerated from it.

## Reproduction and acceptance

Build `vlt1073_test`, `vlt1073_ui_test`, `plugin_probe` and `daw`. Run the DSP
and Qt tests with CTest. The Qt test uses a temporary project/data directory,
not the user's project. For captures, run `vlt1073_ui_test --screenshots PATH`
with `QT_QPA_PLATFORM=offscreen`, `VLT_GPU_WORKSPACE=0` and `QT_SCALE_FACTOR`
set to `1`, `1.5`, then `2` in separate processes.

`python scripts/measure-vlt1073.py` writes the exact probe command lines,
individual CSVs and an Arturia comparison into `artifacts/vlt1073/measurements`.
The optional Arturia path can be changed with `--arturia`. Only black-box audio
and parameter measurements are used; no reference plugin assets or DSP code
are copied. Every sweep uses 48 kHz, 257-frame blocks, a half-second settling
period and a one-second coherent analysis window. Two-tone IMD and folded
high-frequency harmonics have separate measurements. Harmonics beyond Nyquist
use the sentinel −400 in the ordinary harmonic columns, with folded energy
reported separately. These numbers are test conditions, not universal noise
or distortion specifications.

`python scripts/check-vlt1073-circuit.py` independently stamps normalized
complex RC/RLC impedances and solves their node equations. Its numerical
agreement verifies the implemented reduction; it **does not certify the
original Neve circuit**. Arturia comparison uses Type 1, equal physical
endpoint frequencies and signal levels. EQ deviations remove each plugin's
own flat response. Input knob values are reported independently because
Arturia's gain compensation and sensitivity scale are different. A comparison
with Arturia must not be described as validation against hardware or UAD.

Measured results and the visual review are saved in
`artifacts/vlt1073/acceptance.md` alongside the actual Qt screenshots.
