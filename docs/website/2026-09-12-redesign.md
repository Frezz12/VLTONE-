# VLTone website redesign

The public RU/EN site uses the supplied Augen Pro style reference: #f2f2f4 canvas, #fdfdfd surfaces, #0f1012 text, #0071e3 links and outlines, 350/400 Inter, 27px headings, -0.02em tracking, 54px cards, 94px section spacing and no shadows or blue button fills. Fonts and their OFL license ship locally. The admin console retains its existing theme.

The homepage explains the DAW, its audience, recording, MIDI, mixing, plugins, AI and recovery. Open beta onboarding leads through registration, download/install and signing in to the desktop application with the same account. The account page provides the next download step. Public branding is **VLTone**; the actual `/Applications/VLTONE.app` installation path is preserved in the existing macOS download instructions.

Localized titles, descriptions, canonical URLs, hreflang, Open Graph/Twitter previews, WebSite/SoftwareApplication JSON-LD, sitemap and robots are provided. Account/auth pages use `noindex`. Search engines decide when to recrawl and which snippet to display.

## Fresh application screenshots

The hero uses genuine screenshots captured on 2026-09-12 from `build/bin/VLTONE`, with the built-in `dark` preset, clean isolated preferences, a generated demo session and no live audio device. There is no generated portrait on the website.

Assets: `web/public/images/workspace-dark-ru.png` and `workspace-dark-en.png`, each 1600×1000. The existing manual screenshots are retained separately.

Reproduction, from the repository root (repeat with `en` and a separate preferences directory):

```sh
QT_QPA_PLATFORM=offscreen \
DAW_PREF_DIR=/private/tmp/vltone-site-shot-ru \
DAW_SHOT_SIZE=1600x1000 \
DAW_SHOT_MIXER=330 \
DAW_SHOT_DELAY=1000 \
build/bin/VLTONE --theme dark --language ru \
  --screenshot web/public/images/workspace-dark-ru.png
```

- `WEB_UPDATE.json` records the web-only overlay; `SHA256SUMS` covers the staged release. The original release remains available for rollback.

The public screenshot bytes match the local files. All three production services are active. No database migrations or account-data changes were performed.

Rollback for this web-only update: atomically restore `current` to `/opt/vlt-account-platform/releases/0.1.9-0a37208` and restart `vlt-account-web`. The saved standard platform rollback tool also remains available for a full platform rollback.
