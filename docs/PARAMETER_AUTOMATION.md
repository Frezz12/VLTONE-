# Создание автоматизации параметров

Правый клик по параметру → **Create Automation Clip** создаёт автоматизацию
независимо от режима верхней панели.

Кнопка создания автоматизации над треками включает и выключает режим, в котором
двойной клик по параметру создаёт автоматизацию. То же переключение доступно
через **Command + Shift + U** на macOS и **Ctrl + Shift + U** на Windows.
Команда `tool.automationCreationToggle` переназначается в настройках сочетаний;
подсказка кнопки показывает её текущее сочетание. Command/Ctrl + Shift + A
остаётся командой снятия выделения в Piano Roll.

| Было | Стало | Зачем |
| --- | --- | --- |
| Удержание Alt/Option включало создание автоматизации | Режим включается кнопкой или отдельной командой | Alt/Option свободен для других сочетаний |
| Alt/Option + двойной клик создавал автоматизацию | При выключенном режиме двойной клик сбрасывает параметр, включая клик с Alt/Option | Автоматизация создаётся явным действием |
| Подсказки рекомендовали Alt/Option | Подсказки объясняют контекстное меню и кнопку режима | Подсказки соответствуют поведению |

`VLTONE --selftest` проверяет создание через настоящее контекстное меню, повторный
вызов без дублирования дорожки, кнопку режима, четыре типа регуляторов,
переключение с клавиатуры и независимую команду с Alt/Option.
