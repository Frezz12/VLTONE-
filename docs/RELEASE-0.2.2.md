# VLTONE 0.2.2

## Изменения

- Offline Render заменяет выбранные аудиоклипы готовыми файлами и сохраняет
  исходник и каждый следующий результат в истории сэмплера. История доступна
  через Clip FX; команда правого клика возвращает исходный звук. Новое окно
  рендера открывается с пустой цепочкой. Список клипов показывает, что будет
  обработано, а компактные Inserts оставляют больше места для выбора.
- «Общие плагины» добавляют настроенную цепочку на несколько дорожек или
  аудиоклипов. Источник прослушивания выбирается из выделения; применение
  создаёт независимые экземпляры с одинаковыми настройками. Открытие — кнопка
  контекстной панели, меню правого клика или Cmd+Shift+P / Ctrl+Shift+P.
- Перетаскивание BPM: 10 пикселей на 1 BPM, с Shift — на 0,1 BPM. Повторные
  события указателя не ускоряют изменение; дробное значение сохраняется.
  Двойной щелчок позволяет ввести число. Один жест создаёт один шаг Undo.
- Колесо мыши и прокрутка трекпадом над фейдерами каналов и мастера больше
  не меняют громкость. Ручное перетаскивание и Undo работают как прежде.
- Завершение приложения дожидается фонового чтения изображений темы, прежде
  чем Qt освобождает свои графические плагины.

В сборку также входят подготовленные в рабочем дереве улучшения GPU-микшера,
перетаскивания Inserts, жизненного цикла редакторов плагинов и эффектов модуляции,
включая Doubler Pro. Изменения сайта VLTone с описанием открытого бета-теста
и настоящими снимками программы сохраняются в том же исходном коде релиза.

## Сборка

Источники версии — `CMakeLists.txt` и `vcpkg.json`: `0.2.2` без суффикса.
`packaging/macos/build-pkg.sh 0.2.2` создаёт `build-pkg/VLTONE-0.2.2.dmg`
и пакет PKG. Сборка использует производственный API `https://vltstudio.ru/api/v1`
и включает проверки готовности команд совместной работы.

Offline Render и «Общие плагины» доступны в локальных проектах. Проверки
сторонних эффектов используют тестовые плагины; конкретная установленная
версия Auto-Tune требует отдельной проверки с её лицензией.
